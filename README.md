# Jaime Vélez Escandón — Resume

Sitio estático bilingüe (ES/EN) publicado en GitHub Pages: https://jaimevlz.github.io/resume/

- `index.html` — estructura de la página
- `style.css` — identidad visual (plano técnico + acuarela), modo claro/oscuro
- `data.js` — **todo el contenido** (perfil, proyectos, experiencia, habilidades) en español e inglés. Para actualizar el resume, edita solo este archivo.
- `app.js` — render, cambio de idioma/tema, filtros y acuarela generativa
- `cv/` — CV en PDF (ES y EN) que se descarga desde el botón "Descargar CV"

Sin dependencias ni build: se publica tal cual.
